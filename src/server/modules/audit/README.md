# audit

Запись и чтение аудит-трейла. Зависит только от `db`.

- `hash-chain.ts` — канонический JSON, SHA-256, `genesis` для первой записи.
- `reason.ts` — чистое правило обязательной причины (без побочных эффектов).
- `write.ts` — атомарная запись под `pg_advisory_xact_lock`; хеш считает сервис, не вызывающий.
- `read.ts` — постраничное чтение и оконная верификация цепочки.
